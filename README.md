# BiGithubFlow2026: Сервис планирования расписаний (Schedule Planning Service)

Проект разработки сервиса планирования учебного расписания на **Python 3.12+ (FastAPI + SQLAlchemy 2.0)** в рамках курса «Процесс DevOps» (МФТИ, кафедра 1С).

Разработка ведётся распределённой командой по модели **GitHub Flow**.

## Запуск приложения

Из корня репозитория запускаем PostgreSQL, API и веб-интерфейс:

```bash
docker compose up --build
```

Открываем `http://localhost:8080`. Инструкции по разработке фронтенда и настройкам API находятся в [frontend/README.md](frontend/README.md).

## Модель разработки (GitHub Flow)

1. Основная ветка `main` всегда стабильна и развертываема.
2. Для каждой задачи из бэклога создаётся ветка вида: `feature/issue-<id>-<short-description>`.
3. Разработчики (Ваня, Коля, Вася) работают в своих ветках, пишут код и автотесты.
4. Создаётся Pull Request в `main` со ссылкой на соответствующий Issue.
5. GitHub Actions запускает линтеры (`ruff`, `mypy`) и тесты (`pytest`).
6. После прохождения проверок и ревью изменения вливаются в `main`.
